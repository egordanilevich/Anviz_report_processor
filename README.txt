ПО для преобразования исходного отчета системы Anviz AIM CrossChex в требуемый формат.
Исполняемые файлы находятся в папке dist.
Версии программы отличаются только проработкой интерфейса.
Процесс работы:
1) Получить отчет формы "отчет событий по датам" из AIM CrossChex.
2) Перевести отчет в современный формат XLSX (сохранить как ... -> XLSX).
3) Запустить программу.
3) Выбрать файл исходных данных полученный на шаге 2.
4) Выбрать файл для записи или ввести его название (если выбран существующий файл
все данные в нём будут потеряны).
5) Запустить обработку и дождаться её окончания.

Примечание: 
1) Поле должность оставлено Пустым тк ни одни из отчетов системы 
не содержит эту информацию, однако ее можно будет получить, если доработать подгрузку
файла с расписанием сотрудников, где можно указать должность.
2) В случае опоздания или раннего ухода сотрудника соответствующие 
ячейки подсвечиваются красным как в примере.
3) Перед обработкой файл НЕОБХОДИМО конвертировать в XLSX Формат, иначе вохникнет ошибка
(возможно позже допилю обработку XLS).
